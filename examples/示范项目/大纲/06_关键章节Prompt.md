# 关键章节 Prompt

> 用途：关键章节的写作 Prompt 模板，确保重要场景不偏离设计意图
> 使用：Phase 2.6 大纲审批时，关键章节从此加载 Prompt 框架

---

## Prompt 模板格式

每章 Prompt 包含：
- **章节定位**：本章在全书/本卷中的位置
- **核心目标**：本章必须达成的 1-2 个叙事目标
- **约束条件**：不可触犯的设定/时间线/POV 约束
- **风格锚点**：本章应突出的文风特征
- **禁区**：本章绝对不可出现的内容

---

## 关键章节 Prompt 列表

### 第 1 章：{章名}（开篇）

```
【章节定位】全书开篇，确立主角人设、世界观基调、金手指悬念
【核心目标】
  1. 立住主角人设（性格/处境/能力）
  2. 埋下金手指/主线悬念
【约束条件】
  - POV 限知：主角当前所知即读者所知
  - 不可提前泄露后续秘密
【风格锚点】
  - 开场快节奏，直入核心冲突
  - 对话推剧情，心理藏动作
【禁区】
  - 不可堆砌设定
  - 不可长篇背景介绍
```
