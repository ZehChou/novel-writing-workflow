# 卷切换工作流（Volume Transition）

> 长篇小说跨卷一致性保障。在卷末章 P5 归档后、新卷首章 P1 前执行。详见 SKILL.md 阶段表"卷末章特殊处理"。

## 目录
1. 卷末收束
2. 新卷开启
3. 触发与口令

## 1. 卷末收束

卷末章归档完成后的额外收束步骤（在 P5 十步之后）：

1. **L2 定稿**：生成/更新 `正文/摘要/卷{NN}.brief.md`，含本卷核心事件线、角色关系变化、角色弧线进展、未回收跨章钩子、下一卷承接点
2. **L3 全篇更新**：更新 `正文/摘要/全篇.brief.md`（800-1000 字超精简叙事线，格式见 context-budget.md）
3. **伏笔审计**：扫 `promises.jsonl`，intra-volume 未回收项必须在本卷闭合或显式转 cross-volume；逾期项列清单（见 canon-tracking.md 伏笔生命周期）
4. **谜题审计**：扫 `mysteries.jsonl`，核对本卷 `planned_reveal_chapter` 已到期项是否已揭示；未揭示的调整计划章号或标记延期
5. **节奏图谱大高潮校验**：本卷大高潮章（如 Ch10/20/30）实际情绪强度是否到位（见 style-and-pacing.md）
6. **快照**：执行 `bash scripts/snapshot.sh {卷末章号}`（卷收尾必触发，不受周期限制）
7. **canon 完整性自检**：`bash scripts/validate.sh {卷末章号} --canon` 全绿

## 2. 新卷开启

新卷首章 P1 大纲拆解前的准备：

1. **新卷大纲**：生成 `大纲/{NN}_第X卷总纲.md` 与 `大纲/{NN}_第X卷细纲.md`（参考 `02_卷总纲`/`05_细纲` 模板结构）
2. **角色出场重置**：列出本卷固定出场角色、新登场角色、退场角色；更新角色档案"本卷定位"
3. **节奏周期归零**：本卷第 1 章起重新计算小高潮(÷3)/大高潮(÷10)周期；在 `追踪/节奏图谱.md` 标注"卷{N}起始"
4. **承接点确认**：从上一卷 L2"下一卷承接点"读取，确认新卷首章承接上一卷悬念
5. **跨卷钩子清单**：从 `promises.jsonl` 过滤 `scope:cross-volume` 且 `status:pending`，列入本卷待回收清单
6. **谜题释放规划**：从 `mysteries.jsonl` 过滤 `planned_reveal_chapter` 落在本卷的项，排入本卷释放计划

## 3. 触发与口令

- 卷末章 P5 归档后，AI 主动提示「检测到卷末章，是否执行卷末收束？」
- 用户确认后按卷末收束 7 步执行
- 新卷首章 P1 前，AI 提示「检测到新卷开启，是否执行新卷开启准备？」
- 口令："卷末收束" / "新卷开启"
