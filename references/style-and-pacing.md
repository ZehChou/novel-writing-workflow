# 文风与节奏（Style & Pacing）

> SKILL.md 第六节详细参考。含单章节奏度量与跨章节奏图谱。

## 目录
1. 通用文风原则
2. 节奏度量（单章可操作指标）
3. 去AI味与招牌词节制
4. 跨章节奏图谱

## 1. 通用文风原则

- **句式**：短句优先、动词强、形容词少；对话推剧情、心理藏动作/微表情
- **五感**：视/听/嗅/触/味 ≥2 种/场景
- **节奏**：起笔快、中段铺垫、尾部钩子；章内"动-静-动"
- **信息密度**：单章新增有效信息 ≥ 配置值（身世/势力/功法/关系/谜题）

## 2. 节奏度量

- **动作场景占比**：每章动作/对话/事件推进场景 30-50%（纯日常章可低至 20%）
- **连续静场上限**：纯描写/独白/无对话连续段落 ≤800 字，超则插对话或动作打断
- **尾部钩子区**：最后 300 字必须出现新信息/悬念/情感转折，禁"他睡着了/她走了"式平淡收尾
- **段落开头多样性**：连续 3 段不以同一主语开头（如"林一+动词+了"），可用物象/时间/环境变换

## 3. 去AI味与招牌词节制

- 禁词清单见 `project-config.md` 去AI味禁词
- 幽默靠**反差动作/冷面吐槽/旁人视角**落地，不靠标签堆砌
- 不主动解释梗、不元叙事自指、不破第四面墙
- 标识性高频词单章 ≤3 次，不在相邻场景连续出现；可用指代/身体动作/物象替代直呼

### 严肃场景的喜剧注入技法

喜剧不应因场景"严肃"而缺席——轻小说的本质是"严肃时刻的轻松错位"。以下是战斗/危机/情感重场中的喜剧注入方式：

| 场景类型 | 喜剧技法 | 示例 |
|---------|---------|------|
| 战斗 | 实力差距描写的轻描淡写 | 林一单手接住魔兽全力一击，打了个哈欠（不渲染战斗紧张，削弱冲突） |
| 危机 | 主角内心吐槽或与系统闲聊 | 封印崩裂的前一秒，林一心里想的是"统子，这算工伤吗" |
| 情感重场 | 第三者旁观或无关细节闯入 | 告白/道歉前，某只鸡（玄凤）不合时宜地叫了一声 |
| 调查/交涉 | 认知错位的官方术语碰撞 | 骑士一本正经念调查令，林一蹲在旁边拔萝卜 |
| 敌人登场 | 降低逼格的"掉链子"细节 | 魔王出场台词没说完被门框撞到头 |

**核心原则**：喜剧是轻小说的呼吸，不是调味料。战斗中可以没有血迹但不能没有吐槽，危机中可以没有阳光但可以没有"你的对手是元婴期"。错位感本身就在讲故事。

## 4. 跨章节奏图谱

位置：`追踪/节奏图谱.md`。每章归档时追加一行，记录在高潮周期中的位置。

行格式：

| 章号 | 卷 | 类型 | 小高潮位(章号÷3) | 大高潮位(章号÷10) | 实际情绪强度 | 备注 |

- 小高潮周期默认 3 章（Ch3/6/9...），大高潮周期默认 10 章（Ch10/20/30...），均可在 `project-config.md` 配置
- 小高潮=冲突升级或情感爆发点；大高潮=卷内核心事件收束
- **P2.5 写前检查**：本章章号是否命中高潮周期 -> 是则提示"本章应为高潮章"
- **P3.5 校验**：高潮章实际情绪强度是否到位（非平淡章）；非高潮章避免强行加戏
- 图谱维护：P5 归档时由归档者追加本章行；卷收尾时在 volume-transition 流程中校验全卷节奏曲线

## 5. 对话专项自检详细指南（P3.2 配套参考）

P3.2 第4项"对话专项自检"的详细操作说明与判断标准。

### 5a. 声纹一致性

**方法**：抽取出场角色各3句对白，复制到一个空白段，遮住角色名，读一遍。

**判断标准**：
- ✅ 能凭语气/节奏/用词认出角色 = 通过
- ❌ 认不出或需要猜 = 不通过

**常见声纹混淆与修正**：

| 混淆对 | 问题 | 修正方向 |
|--------|------|---------|
| 林一↔艾伦 | 两人都话少冷静 | 林一用省略号+短句（"……行吧"），艾伦用完整句式（"从数据上看"） |
| 露露↔凯恩 | 两人都用感叹号 | 露露跳跃式话题，凯恩复读式强调（"我是男的！男的！"） |
| 莉亚↔系统 | 两人都正式 | 系统用公务员腔（"数据已更新"），莉亚用骑士腔（"以骑士之名"） |

### 5b. 潜台词检查

**核心标准**：每场景至少1处"说的≠想的"。

**常见技法**：
- **不说破**：不说"我喜欢你"，说"以后还能来吗？"
- **口是心非**：说"还行"，眼神没离开过茶杯
- **转移话题**：被问到不愿答的问题，反问对方或指别处
- **用动作回答**：不说"是"，沉默两秒后给对放茶杯续水
- **被戳穿时的反应**：不说"你怎么知道"，而是手指停在半空

**检查方式**：标出每个场景中"角色直接说出了感受/意图"的台词 → 考虑能否改为间接表达。

### 5c. 信息倾倒检测

**红线**：角色向另一个角色解释对方本应知道的事。

**典型样例**：
```
❌ "艾伦，你知道我们冒险者公会每个月都要提交任务报告的。"
✅ （艾伦从怀里掏出一份皱巴巴的任务报告，按在桌上。）
```

**检测方式**：
- 逐句问：这句信息，听众角色是否已经知道？
- 如果知道 → 删除或转为动作/环境承载
- 如果是向读者解释 → 通过第三人称叙述而非角色对话

### 5d. 对话节奏变化

**测试方法**：扫一遍本章对话，统计每句的字数。

**典型问题**：连续5句以上字数相近（尤其对话密集场景）。

**修正技法**：

| 现状 | 修正 |
|------|------|
| 连续短句 | 插入1-2句较长的叙述或内心OS |
| 连续长句 | 用动作打断（"他顿了顿"），或让角色只说一半 |
| A说→B说→A说→B说 | 插入第三人打断、沉默段落、动作描写、场景切换 |

### 5e. 乒乓球检测

**定义**：连续3组以上"A说→B说→A说→B说"的无打断对话，即"乒乓球对话"。

**修正方法**（至少选1处应用）：
1. **打断**：新角色或外部事件闯入对话
2. **沉默**：角色不接话，放慢节奏（"林一没回答。端起茶杯喝了一口。"）
3. **动作**：说话间插入动作（"他说着，把锄头放下"）
4. **跑题**：角色的回应偏离对方问题（"这个你吃吗？"——"你锅烧干了。"）
5. **答非所问**：角色不回答对方问题，用动作/沉默/反问代替

**判断标准**：对话密集区段（连续5行以上），至少出现1处非直接回应。

## 6. 情感递进检查指南（P3.5 配套参考）

### 6a. 单场景情感移动距离

每个场景结束时，角色情绪应与开场不同，哪怕只是"从警惕到好奇"的半步移动。

**无情感移动 = 多余场景**。如果一个场景开始和结束角色情绪一致，考虑合并或删除该场景。

### 6b. 跨场景情感流

| 场景 | 结尾情绪 | → | 下场景 | 开场情绪 | 衔接检查 |
|------|---------|---|--------|---------|---------|
| 战斗 | 紧绷/肾上腺素 | → | 日常 | 放松/疲惫 | 需过渡（回程路途/换衣服/泡茶） |
| 情感暴露 | 尴尬 | → | 日常 | 假装无事 | 可用沉默+动作呈现（多盛一碗饭） |

不同情绪之间需要过渡桥段，不可"上一秒剑拔弩张，下一秒谈笑风生"。

### 6c. 关系递进的动作承载

关系变化必须通过**外部可观察的行为**呈现，不可通过角色宣告。

| 关系变化 | 允许 | 不允许 |
|---------|------|--------|
| 从陌生到信任 | "他接过对方递来的茶杯，没有犹豫" | "他开始信任他了" |
| 从尴尬到自然 | "她坐下时，下意识往他那边挪了半寸" | "她感到不再尴尬了" |
| 从冲突到和解 | 沉默片刻后，对方主动给他添茶 | "我们和好吧" |

### 6d. 情感递进硬性要求（P3.5）

每章检查清单：
- [ ] 至少1段关系发生可感知的变化（生→熟 / 冷→热 / 紧张→放松 / 陌生→好奇）
- [ ] 变化通过动作/对话/细节承载，非叙述直告
- [ ] 结尾情绪 ≠ 开头情绪（整体弧线）
- [ ] 跨场景情绪衔接流畅，无突兀跳跃
