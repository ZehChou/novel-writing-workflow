# 对白二稿与幽默校准（Dialogue Revision）

> 配套 `SKILL.md` 的 P2.7、P2.75、P3.25、P3.5 使用。目标不是让对白“技巧更多”，而是让每句台词都由具体人物、具体关系和具体压力产生。

## 1. 基本原则

- **人物先于技巧**：先决定说话人想得到什么、怕失去什么，再决定他接话、回避、打断还是沉默。
- **回应可以正常**：接住对方的话不是“乒乓球对白”。只有关系、压力或信息不对称要求时，才使用回避、答非所问和沉默。
- **声纹是决策方式，不是口癖集合**：句长、标点和语气词只能辅助识别；核心是该人物如何处理请求、尴尬、冲突、关心与秘密。
- **笑点不需要说明书**：人物、叙述者和旁观者不得替读者解释某句为什么好笑、某人为什么显得厉害。
- **可以没有笑点**：严肃、悲伤或信息密集场景可以保持压力；轻松感不是每一场的交付指标。

## 2. P2.7 对白冲突卡

对白密集的场景，除常规场景卡外，必须补齐以下字段：

```md
- 说话人 A：想得到 / 不愿暴露 / 让步底线
- 说话人 B：想得到 / 不愿暴露 / 让步底线
- 关系压力：地位、旧账、第三人在场、时间限制或信息差
- 回合转折：哪一句、哪个动作或哪个外部事件改变了谈话方向
- 可接受的回应类型：接住 / 回避 / 反问 / 打断 / 误解 / 转移 / 沉默
- 不可说出的解释：人物不能替作者、读者或自己说明什么
```

若场景使用幽默，再追加：

```md
- 是否需要幽默：需要 / 不需要
- 幽默来源：人物习惯 / 信息差 / 已建立回响 / 物件与场合错位
- 谁能理解、谁不能理解：
- 幽默后的变化：关系、地位、信息或情绪至少有一项移动
- 禁止：解释笑点、重复追打同一笑点、使用外部热梗
```

## 3. P2.75 关键对白预演

有关键对白的场景必须执行；只有独处、纯动作或纯叙述场景可跳过。每位关键说话人填写：

1. 这一场最想从对方得到什么？
2. 最不愿被对方看见什么？
3. 会认真接住对方哪一句？
4. 可能回避哪一个问题，原因是什么？
5. 绝不会说出的原句是什么？

随后用 80–150 字只写对白进行试音。试音不进入正文，不要求搞笑；重点是让角色针对**此刻的对象**说话，而不是展示口头禅。

## 4. P3.25 对白二稿

### 4a. 抽离测试

抽取关键场景的全部对白，暂时隐藏说话人名和叙述。逐段检查：

| 项目 | 0 分 | 1 分 | 2 分 |
|------|------|------|------|
| 人物目的 | 没有明确目的 | 只有一方有目的 | 双方目的不同且彼此影响 |
| 关系压力 | 可由任意两人说 | 有轻微身份/旧事影响 | 只有这两个人、此刻才能这样说 |
| 潜台词 | 全部直说 | 偶有保留 | 有可理解的保留、试探或错位 |
| 声纹 | 换人仍成立 | 有少量差异 | 不看名字也大多能认出 |

关键对白低于 6/8，不做局部补丁，重写该段的对话骨架。

### 4b. 删除与压缩

优先删除或改写以下句子：

- 向熟人解释常识、设定或已经发生的事；
- 角色解释自己的高明、强大、善意或情绪；
- 旁观者替读者总结反差、点评笑点；
- 只是把上一句换词复述、没有新增意图的回应；
- 为了“显得自然”而没有动机的沉默、打断、答非所问。

### 4c. 朗读测试

以正常说话速度朗读关键对话：

- 一口气念不顺的长句，先检查是否在替作者解释；
- 每句话都过分完整、礼貌、有效，补入符合人物动机的停顿或偏移；
- 每句话都故作短促、冷淡，补入真正接住对方信息的完整回应；
- 不以增加省略号、感叹号或动作标签代替人物反应。

## 5. 幽默的通过标准

幽默成立，至少满足以下三项中的两项：

1. 不依赖“这是个梗”的提示或解释；
2. 来自已经建立的人物习惯、关系、信息差或场景物件；
3. 笑点之后，至少有一个人的态度、关系、地位或行动发生变化。

以下情况直接删去笑点：

- 只是在紧张场景中硬塞一句俏皮话；
- 角色以分析、赞叹或总结替读者解释笑点；
- 过去三章已使用同一种反差或同一个物件反复追打；
- 必须依赖现实网络热梗才能成立。

## 6. 对白样本库

在 `知识库/文风样本.md` 维护**作者批准的原创对白片段**。每位常驻角色逐步积累 4–8 组、每组 2–6 轮的高质量样本，按以下场景归类：

- 日常接话
- 拒绝请求
- 关心他人
- 被误会或被戳穿
- 压力/冲突
- 想说但不说
- 轻松回响（非必需）

每组样本需标注：说话对象、场景压力、人物目的、不可替换之处。写作时只加载本章出场角色的 2–3 组相关样本；优先使用作者亲自修订并认可的片段。
