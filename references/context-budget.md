## 1. P2.5 分层加载协议

| 优先级 | 内容 | 来源 |
|--------|------|------|
| **P0 固定加载** | 本章大纲、角色档案、文风样本、档案事件、创作脉络 | 5份必读文件，永远加载 |
| **P1 衔接加载** | 前3章 L1 brief + 当前卷 L2 摘要 + 前章结尾500字 | `正文/摘要/*.brief.md` + 上章归档末段 |
| **P2 实体加载** | 出场角色当前状态 + 已知秘密（`facts.jsonl` 按 `known_by` 过滤） | 角色档案 + `facts.jsonl`，只载入场角色 |
| **P3 伏笔加载** | 档案事件中 status=待回收 或距上次推进>5章的活跃钩子 | 档案事件 + `promises.jsonl` |
| **P4 反查加载** | 按 BM25 召回相关历史章节 L1 brief（`scripts/retrieve.py recall`，最多3篇） | `正文/摘要/` |
| **P5 热梗加载（可选）** | 角色/情绪灵感 | `追踪/参考/网络热梗参考.md`，非强制 |

## 2. 逐段预算上限

超预算按优先级截断，**严禁静默超预算**--每次超预算输出可见警告。

| 上下文段 | max_items | max_total_chars | 截断策略 |
|----------|-----------|-----------------|----------|
| P0 细纲+钩子 | 无限制 | 无限制 | 不截断（核心骨骼） |
| P1 前3章 L1 brief | 3 | 2400 | 只保留最近3章 |
| P2 角色档案+出场状态 | 无限制 | 5200 | 优先出场角色，余按出场频率截断 |
| P3 活跃钩子+正典事实 | 10 | 2400 | 按本章关键词相关性排序取 top-10 |
| P4 BM25反查 | 无限制 | 800 | BM25 top-k，仅保留命中项 |
| P5 热梗灵感 | 3 | 600 | 仅保留明确可用的灵感 |

**全局预算**：所有段加载后总字符 ≤ 15000。超限优先裁剪 P4、P5。

**超预算处理**：加载时计算每段字符数 -> 超预算输出「⚠️ {段名} 超预算 {超出字数} 字，已裁剪」-> 用户可手动「加载完整 {段名}」。

## 3. 钩子健康度检查（P2.5 加检）

加载完毕后快速检查活跃钩子：
1. 从 `promises.jsonl` 过滤 `status:pending`
2. 按 `type` 分类计数：cliffhanger/emotional/lore/setup
3. 按 `scope` 分类：intra-volume（本周回收）vs cross-volume（跨卷不急）
4. 检查连续 3 章只落不收 -> 本章应优先回收旧钩子
5. **逾期检测**：`planned_chapter` < 当前章 且 `status:pending` -> ⚠️ 逾期
6. 检查上一章尾钩是否在本章开头有承接 -> 无则补过渡句

## 4. 上下文窗口衰减实测

> 来源：DreamQuill 实测数据

| 字数区间 | 表现 | 风险 |
|----------|------|------|
| 0-3000字 | 机制正常，人物一致，时间线清晰 | 无 |
| 3000-6000字 | 连续性检查松动，对话模式化（"XX说"重复率+120%） | 低 |
| 6000-8000字 | 流程执行变形，人物状态表不完整，动机记录丢失 | 中 |
| 8000-10000字 | 设定"底线"约束被违反，因果链断裂 | 高 |

**关键发现**：5000-6000 字区间 LLM 会自行触发"收尾模式"--即使指令要求继续写也倾向自动收尾，非提示词可克服。

**应对策略**：
- 字数限安全区：单章 3500-4000 字（0-3000 舒适区边缘）
- P2.5 预算控制：总加载 ≤ 15000 字
- P3.5 收尾模式检测：章末 300 字出现入睡/离开/时间跳跃/总结句且非卷末章 -> ⚠️ 疑似收尾模式
- P3.2 对白辨识测试：遮角色名看能否认出是谁（至少认出一半）
- L3 兜底：溢出时降级 L3 压缩叙事

## 5. 幻觉预警信号

以下任一出现，立即暂停写作回 P2.5 重新组装：
- 角色做出与其"不可违背底线"矛盾的行为
- 对话中角色使用其不应知的信息（POV 泄露）
- 场景描述与 `settings.jsonl` immutable 项矛盾
- 时间线跳跃或倒退
- 连续 3 段以上同一句式结构
