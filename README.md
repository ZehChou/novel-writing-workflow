# Novel Writing Workflow — AI 驱动长篇网文创作全流程管线

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Status](https://img.shields.io/badge/status-production-green.svg)]()

> 一套专为**长篇小说创作**设计的 AI 协作工作流。将百万字长篇拆解为「大纲→素材→写作→校验→归档」的可控管线，让 AI 成为你的写作搭档，而非代笔工具。

---

## 🎯 为什么你需要它？

写长篇最怕什么？**前后矛盾、伏笔烂尾、角色崩坏、节奏失控。**

传统写作工具只能帮你码字，但管不了你的故事逻辑。这套工作流把**正典追踪、伏笔生命周期、POV 知识边界、跨章节奏图谱**全自动化——你只管创作，一致性交给管线。

**核心价值：让你用 AI 写出人味，而不是 AI 味。**

## ✨ 核心卖点

### 🏭 工业化创作管线（Phase 1-5）

```
大纲拆解 → 素材准备 → 写前组装 → 大纲审批 → 场景编剧
    → 正文写作 → 自编辑 → 硬校验 → 查重 → 用户审阅 → 归档入库
```

- **写前必读**：智能加载角色档案、前文摘要、活跃钩子、正典事实，确保每一章都接得上
- **写后硬校验**：8 项自动检测（字数、禁词、POV 泄露、正典冲突、谜题提前泄露、读者-主角同步……）
- **跨章查重**：自动对比最近 N 章，检测场景/对话/意象/情节重复
- **归档入库**：10 步自动化归档，角色档案、时间线、伏笔账本全更新

### 🧬 六维正典追踪系统

长篇连载最大的噩梦——**写到后面忘了前面**。我们用一个 JSONL 数据库解决：

| 维度 | 追踪内容 | 防止的问题 |
|------|---------|-----------|
| 原子事实 | 角色能力上限、物品归属、人物状态 | 前后矛盾 |
| 钩子/承诺 | 伏笔生命周期（计划章→逾期检测→回收） | 伏笔烂尾 |
| 能力进阶 | 数值化追踪，检测回退 | 战力崩坏 |
| 情感状态 | 角色关系 -3~3 量化 + 弧线追踪 | 情感跳跃 |
| 场景注册 | immutable 描述防漂移 | 场景穿帮 |
| 谜题释放 | 分层释放 + 提前泄露检测 | 悬念过早揭晓 |

### 🎭 POV 知识边界管控

**限知视角零泄露**。每个角色只能使用自己知道的信息——系统自动按 `known_by` 过滤，角色不会说出"不该知道的事"。读者与主角同步获取信息，谜题逐层释放。

### 🚫 去 AI 味引擎

AI 写作最大的问题：**读三行就知道是 AI 写的。** 我们内置：

- **禁词硬过滤**：仿佛、宛如、似乎、那一刻、空气中弥漫……一键拦截 AI 高频词
- **文风约束**：短句优先、动词强、形容词少、对话推剧情、心理藏动作
- **对话专项自检**：声纹一致性、潜台词检查、信息倾倒检测、乒乓球对话打断
- **节奏度量**：动作场景占比、连续静场上限、尾部钩子区、段落开头多样性

### 🎌 日式轻小说专项优化

如果你是**なろう系 / 异世界 / 轻小说**作者，这套工作流直接开箱即用：

- 对话驱动叙事（对话占比 ≥50%）
- 吐槽式内心独白（ツッコミ）
- 日常与非日常交替节奏（7:3）
- 萌要素与角色标签化设计
- 男频/女频写作边界控制
- 冰山式信息释放

### 📊 跨章节奏图谱

每章归档自动追加节奏记录，追踪高潮周期（小高潮÷3 / 大高潮÷10），卷末收束时校验全卷节奏曲线，确保"动-静-动"呼吸感。

### 📦 卷切换（Volume Transition）

支持多卷长篇。卷末收束 7 步 + 新卷开启 6 步，自动处理伏笔审计、谜题审计、角色出场重置、跨卷钩子清单。

### 💾 快照与回滚

每 N 章或卷收尾自动快照知识库/摘要/大纲/canon，随时回滚到任意历史版本。

## 🚀 快速开始

### 环境要求

- **AI 工具**：Codex CLI / Cursor / Claude Code / 任意支持 AGENTS.md / SKILL.md 的 AI 编码助手
- **Shell**：Bash 4+（macOS/Linux 默认支持）
- 无其他依赖——所有脚本均为纯 Bash

### 30 秒上手

```bash
# 1. 克隆仓库到你的项目目录
git clone https://github.com/ZehChou/novel-writing-workflow.git
cp -r novel-writing-workflow/templates/* ./你的小说项目/
cp novel-writing-workflow/SKILL.md ./

# 2. 配置你的项目
# 编辑 project-config.md，填写书名、禁词、境界体系、角色名等
# 编辑 知识库/角色档案.md，填入你的角色设定

# 3. 生成 AGENTS.md
bash scripts/generate-agents.sh

# 4. 开始写作
# 对 AI 说："Phase 2.5 启动" 即可开始第一章
```

### 一句话启动

将 `SKILL.md` 和 `templates/` 放入你的项目目录，AI 会自动识别并引导你完成配置。

## 📁 目录结构

```
你的小说项目/
├── AGENTS.md                 # 项目级写作约束（自动生成）
├── project-config.md         # 可编辑配置
├── SKILL.md                  # 工作流定义
├── 大纲/                     # 体量规划、卷总纲、细纲、战力规划
├── 知识库/                   # 角色档案、文风样本、世界基石、时间线
├── 正文/                     # 章节正文 + L1/L2/L3 摘要
├── 追踪/
│   ├── canon/                # 正典六维 JSONL 数据库
│   ├── 节奏图谱.md           # 跨章节奏追踪
│   └── snapshots/            # 快照备份
├── scripts/                  # 自动化脚本
├── templates/                # 资源模板
└── references/               # 详细参考文档
```

## 🎮 执行口令速查

| 口令 | 触发阶段 |
|------|---------|
| `Phase 2.5 启动` | 写前组装（加载上下文 + 钩子健康度） |
| `Phase 2.6 审批` | 输出大纲，等待用户确认"可写" |
| `Phase 3.5 核验` | 硬校验（8 项 + 声纹 + 谜题泄露 + 读者同步） |
| `Phase 3.6 查重` | 跨章查重 |
| `Phase 5 归档` | 十步归档入库 |
| `卷末收束` | 卷末章收束 7 步 |
| `新卷开启` | 新卷首章准备 6 步 |

## 🔧 自动化脚本

| 脚本 | 功能 |
|------|------|
| `validate.sh {NN}` | 章节校验（字数/禁词/正典/谜题/伏笔/节奏） |
| `snapshot.sh {NN}` | 快照备份 |
| `generate-agents.sh` | 从 project-config.md 生成 AGENTS.md |
| `retrieve.py` | BM25 关键词反查历史章节 |
| `gen_docx.py` | 导出为 Word 文档 |

## 💡 适合谁用？

- ✅ **网文作者**：起点、番茄、飞卢、SF轻小说、成为小说家吧（なろう）等平台作者
- ✅ **AI 辅助写作**：想用 AI 提速但不想被 AI 带偏风格
- ✅ **长篇连载**：百万字以上长篇，需要一致性保障
- ✅ **团队协作**：多人合写，需要统一风格和设定约束
- ✅ **写作新手**：想学习结构化写作方法
