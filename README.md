# Novel Writing Workflow — AI 驱动长篇网文创作全流程管线

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Status](https://img.shields.io/badge/status-production-green.svg)]()

> 一套专为**长篇小说创作**设计的 AI 协作工作流。将百万字长篇拆解为「大纲→素材→写作→校验→归档」的可控管线，让 AI 成为你的写作搭档，而非代笔工具。

---

## 🎯 为什么你需要它？

写长篇最怕什么？**前后矛盾、伏笔烂尾、角色崩坏、节奏失控。**

传统写作工具只能帮你码字，但管不了你的故事逻辑。这套工作流把**正典追踪、伏笔生命周期、POV 知识边界、跨章节奏图谱**全自动化——你只管创作，一致性交给管线。

**核心价值：让你用 AI 写出人味，而不是 AI 味。**

## ✨ 核心卖点

### 🏭 工业化创作管线（Phase 1-5）

```
大纲拆解 → 素材准备 → 写前组装 → 记忆预演 → 大纲审批 → 场景编剧
    → 关键对白预演（条件必做） → 正文写作 → 自编辑 → 对白二稿（条件必做）
    → 双重核验 → 查重 → 用户审阅 → 归档入库
```

- **写前必读**：智能加载角色档案、前文摘要、活跃钩子、正典事实，确保每一章都接得上
- **写后双重核验**：脚本检查字数、禁词、POV、正典与谜题；P3.25/文学审稿检查对白、人物关系和幽默
- **跨章查重**：自动对比最近 N 章，检测场景/对话/意象/情节重复
- **归档入库**：10 步自动化归档，角色档案、时间线、伏笔账本全更新

### 🧬 六维正典追踪系统 + 三扩展账本

长篇连载最大的噩梦——**写到后面忘了前面**。我们用一个 JSONL 数据库解决：

| 维度 | 追踪内容 | 防止的问题 |
|------|---------|-----------|
| 原子事实 | 角色能力上限、物品归属、人物状态 | 前后矛盾 |
| 钩子/承诺 | 伏笔生命周期（计划章→逾期检测→回收） | 伏笔烂尾 |
| 能力进阶 | 数值化追踪，检测回退 + 升级过快预警 | 战力崩坏 |
| 情感状态 | 角色关系 -3~3 量化 + 弧线追踪 | 情感跳跃 |
| 场景注册 | immutable 描述防漂移 | 场景穿帮 |
| 谜题释放 | 分层释放 + 提前泄露检测 | 悬念过早揭晓 |

**三扩展账本（★）**：

| 账本 | 追踪内容 | 防止的问题 |
|------|---------|-----------|
| 爽点账本 | 期待感-兑现配对、逾期检测、reader_hit | 爽点烂尾、只设不收 |
| 面板注册表 | 金手指/系统面板 immutable 数值 | 面板数字穿帮 |
| 配角池 | 出场频率、反派智商档位、动机 | 配角用完即弃、反派降智 |

另有**正典归档压缩**（`scripts/archive.sh`）：卷完结后把已闭合条目移入归档区，防百万字长篇 canon 无限膨胀。

### 🎭 POV 知识边界管控

**限知视角零泄露**。每个角色只能使用自己知道的信息——系统自动按 `known_by` 过滤，角色不会说出"不该知道的事"。读者与主角同步获取信息，谜题逐层释放。

### 🚫 去 AI 味引擎

AI 写作最大的问题：**读三行就知道是 AI 写的。** 我们内置：

- **禁词硬过滤**：拦截常见 AI 套话与项目禁词，但不把机械通过误当文学通过
- **文风约束**：短句优先、动词强、形容词少、对话推剧情、心理藏动作
- **关键对白二稿**：先在 P2.75 预演角色目标与底线，再按人物目的、关系压力、潜台词、动态声纹做 8 分抽离评分；低于 6 分重写骨架并朗读复核
- **样本库校准**：只加载作者批准的原创场景化对白，学习回应逻辑而非复制口头禅；允许人物正常接话，不强制沉默、打断或答非所问
- **幽默校准**：笑点可为“无”；不用外部热梗，不解释笑点，不反复追打同一反差
- **节奏度量**：动作场景占比、连续静场上限、尾部钩子区、段落开头多样性

### 🎌 类型化专项优化（含日式轻小说）

开书初始化时按题材选择 profile（见 `references/genre-profiles.md`），自动覆盖节奏参数。**なろう系 / 异世界 / 轻小说**作者开箱即用：

- 对话驱动叙事（对话占比 ≥50%）
- 吐槽式内心独白（ツッコミ）
- 日常与非日常交替节奏（7:3）
- 萌要素与角色标签化设计
- 另有**男频爽文**（打脸"先给后夺"结构、金手指节奏）、**悬疑无限流**（规则推进、信息差）、**女频言情**（拉扯动机、感情弧）专项参数

### 📊 跨章节奏图谱

每章归档自动追加节奏记录，追踪高潮周期（小高潮÷3 / 大高潮÷10），卷末收束时校验全卷节奏曲线，确保"动-静-动"呼吸感。

### 📦 卷切换（Volume Transition）

支持多卷长篇。卷末收束 10 步 + 新卷开启 6 步，自动处理伏笔审计、谜题审计、**爽点审计**、面板/配角池审计、正典归档压缩、角色出场重置、跨卷钩子清单。

### 🌟 黄金三章专项 + 单章推进标准

- **黄金三章**：Ch1-3 强制 `validate.sh --opening`——金手指悬念、人设三要素、小爽点闭环、世界观零倾倒、钩子密度逐项检查
- **单章推进**：字数达标 ≠ 有效章。每章必须有**有效推进项**（信息/关系/战力/爽点/目标任一），为 0 直接判"需重写"

### 📈 读者反馈复盘（P4.5）

网文是数据驱动的连载。每卷一次把追读率/章评/订阅录入 `追踪/复盘.md`，标记**哪些爽点读者买账**（reader_hit）、定位流失点，反哺节奏图谱/细纲/人设。调整只依据读者数据，不依据 AI 的自我感觉。

### 💾 快照与回滚

每 N 章或卷收尾自动快照知识库/摘要/大纲/canon，随时回滚到任意历史版本。

## 🚀 快速开始

### 环境要求

- **AI 工具**：Codex CLI / Cursor / Claude Code / 任意支持 AGENTS.md / SKILL.md 的 AI 编码助手
- **Shell**：Bash 4+（macOS/Linux/Git Bash for Windows）
- **Python 3**：`retrieve.py`（BM25 检索/查重）、`validate.sh` 的伏笔/谜题/爽点/战力等检测、`gen_docx.py` 需要——**仅标准库，零第三方依赖**

### 30 秒上手

```bash
# 1. 克隆仓库到你的项目目录
git clone https://github.com/ZehChou/novel-writing-workflow.git
cp -r novel-writing-workflow/templates/* ./你的小说项目/
cp novel-writing-workflow/SKILL.md ./

# 2. 配置你的项目
# 编辑 project-config.md，填写书名、禁词、境界体系、角色名等
# 编辑 知识库/角色档案.md，填入你的角色设定

# 3. 生成 AGENTS.md
bash scripts/generate-agents.sh

# 4. 开始写作
# 对 AI 说："Phase 2.5 启动" 即可开始第一章
```

### 一句话启动

将 `SKILL.md` 和 `templates/` 放入你的项目目录，AI 会自动识别并引导你完成配置。

## 📁 目录结构

```
你的小说项目/
├── AGENTS.md                 # 项目级写作约束（自动生成）
├── project-config.md         # 可编辑配置
├── SKILL.md                  # 工作流定义
├── 大纲/                     # 体量规划、卷总纲、细纲、战力规划
├── 知识库/                   # 角色档案、文风样本、世界基石、时间线
├── 正文/                     # 章节正文 + L1/L2/L3 摘要
├── 追踪/
│   ├── canon/                # 正典六维 + 爽点/面板/配角池账本 + archive 归档区
│   ├── 节奏图谱.md           # 跨章节奏追踪（含爽点兑现/追读列）
│   ├── 复盘.md               # 读者反馈复盘（P4.5）
│   └── snapshots/            # 快照备份
├── scripts/                  # 自动化脚本（validate/archive/snapshot/gen_docx/retrieve）
├── templates/                # 资源模板
├── references/               # 详细参考文档（含失败模式/类型化/读者复盘）
└── examples/                 # 可运行的示例项目（3 章端到端）
```

## 🎮 执行口令速查

| 口令 | 触发阶段 |
|------|---------|
| `Phase 2.5 启动` | 写前组装（加载上下文 + 钩子健康度 + 批准对白样本） |
| `Phase 2.55 预演` | 记忆预演（角色/场景/钩子/情绪/正典） |
| `Phase 2.6 审批` | 输出大纲，等待用户确认“可写” |
| `Phase 2.7 拆场景` | 场景编剧卡（含人物目标、关系压力与轻松策略） |
| `Phase 2.75 对白预演` | 关键对白试音（有关键对白时必做） |
| `Phase 3.2 自编辑` | 基础编辑（文字、段落、标签与动作） |
| `Phase 3.25 对白二稿` | 抽离评分、重写与朗读测试 |
| `Phase 3.5 核验` | 机械硬校验 + 文学审稿（对白/POV/正典/谜题） |
| `Phase 3.6 查重` | 跨章查重 |
| `Phase 5 归档` | 十步归档入库 |
| `卷末收束` | 卷末章收束 7 步 |
| `新卷开启` | 新卷首章准备 6 步 |

## 🔧 自动化脚本

| 脚本 | 功能 |
|------|------|
| `validate.sh {NN}` | 章节机械校验（字数/禁词/正典/谜题/伏笔/节奏/**爽点/黄金三章/战力/面板/配角池**；不自动证明对白自然） |
| `snapshot.sh {NN}` | 快照备份 |
| `archive.sh {卷号} {章号}` | 正典归档压缩（卷完结后防 canon 膨胀） |
| `generate-agents.sh` | 从 project-config.md 生成 AGENTS.md |
| `retrieve.py` | BM25 关键词反查历史章节 |
| `gen_docx.py` | 导出为 Word 文档 |

## 💡 适合谁用？

- ✅ **网文作者**：起点、番茄、飞卢、SF轻小说、成为小说家吧（なろう）等平台作者
- ✅ **AI 辅助写作**：想用 AI 提速但不想被 AI 带偏风格
- ✅ **长篇连载**：百万字以上长篇，需要一致性保障
- ✅ **团队协作**：多人合写，需要统一风格和设定约束
- ✅ **写作新手**：想学习结构化写作方法
