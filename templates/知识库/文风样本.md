### 作者批准的对白样本库

> 每位常驻角色至少积累 8 组原创片段，每组 2–6 轮。写作前按场景只加载本章出场角色的 2–3 组，不用外部作品或网络热梗代替。

| 角色 | 场景 | 对话对象 | 场景压力 | 人物目的 | 不可替换之处 | 批准片段位置 |

| | 日常接话 / 拒绝请求 / 关心他人 / 被戳穿 / 压力冲突 / 想说不说 / 轻松回响 | | | | | |
